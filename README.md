# NumPy Analyzer

## About The Project

NumPy Analyzer is a simple menu-driven Python project created to practice NumPy and basic data analysis operations.

The project allows users to create different types of NumPy arrays and perform various operations on them through an easy-to-use command-line menu.

It is mainly designed for beginners who want to understand how NumPy works with arrays, mathematical operations, searching, sorting, filtering, and statistical calculations.

---

## Features

- Create 1D, 2D, and 3D NumPy arrays
- Perform array indexing
- Perform array slicing
- Addition of arrays
- Subtraction of arrays
- Multiplication of arrays
- Division of arrays
- Dot product
- Matrix multiplication
- Combine arrays
- Split arrays
- Search values in an array
- Sort arrays in ascending or descending order
- Filter array values
- Calculate sum
- Calculate mean
- Calculate median
- Calculate standard deviation
- Calculate variance
- Find minimum and maximum values
- Calculate percentile
- Menu-driven interface
- Press Enter to continue option
- Basic input validation

## How It Works

When the program starts, it displays a menu containing different NumPy operations.

The user can first create an array and then perform operations such as indexing, slicing, mathematical calculations, searching, sorting, filtering, and statistical analysis.

After completing an operation, the program asks the user to press Enter before returning to the menu.

The program continues running until the user selects the Exit option.
